# Splattt!

Kitchen extermination arcade. Smash flies. Spend the mess.

Tap pests, stack combos, buy upgrades, unlock rooms, fumigate for prestige.

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:8080`.

## Stack

React 19, TanStack Start, Canvas 2D, Tailwind. Save lives in `localStorage`. No account required.
